# P0 时间线修复

- 历史投影保留原始正文，计划留在 metadata，不再被当作完成记录。连续性引用实际正文末尾并标注截断；场景锚点取实际正文，不再复制计划末尾或 carry。原文与传输记录仍分别保留。
- 压缩输入增加故事时区的日期、星期、时间及事实来源。压缩结果写入前核验来源 ID，并独立审核摘要、事实、事项关闭、状态补丁的时间与因果。不确定、拒绝、服务错误均保留原始条目和压缩检查点，走已有失败退避重试。
- 日程按本轮 from 到未来窗口投影，按规则补出昨日跨夜安排；recentBlocks 单独提供本轮已结束的计划，仍标识 plannedNotObserved。过去计划不会触发未来调度。

验证覆盖跨午夜本地日期、跨夜班次、已结束计划隔离、原文场景锚点，以及记忆审核缺失、不确定和伪造来源的回归测试。最终验证与后续修复见[审核器、恢复边界与旧规则清理](2026-09-08-review-boundary-cleanup.md)。

限制：代码升级不会自动清洗历史事实；语义审核依赖模型服务，服务不可用时压缩会保留原文等待重试。部署时应备份原始数据库，并独立确认运行包版本与服务健康。
